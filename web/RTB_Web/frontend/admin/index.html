🛠️ Comandos esenciales

Ejecutar en el servidor (carpeta mailserver/).

cd /opt/proyectos/rtb/mailserver

docker compose ps                 # estado
docker compose up -d              # levantar
docker compose down               # detener
docker compose restart            # reiniciar
docker logs --tail 200 mailserver # ver logs
docker exec mailserver setup email list   # listar buzones
docker stats --no-stream mailserver       # CPU / memoria
